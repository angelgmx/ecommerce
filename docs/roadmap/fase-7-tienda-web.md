# Fase 7 · Tienda web

- **Estado:** pendiente
- **Fechas:** 29 ene – 12 feb 2027
- **Versión al cerrar:** `v0.7.0`

## Objetivo

La tienda que usa el cliente y el panel de administración, consumiendo la API.

## Entregables

- [ ] Aplicación Next.js en `apps/web` dentro del monorepo.
- [ ] Catálogo, ficha de producto, carrito y pago.
- [ ] Sesión de usuario.
- [ ] Panel de administración del catálogo y los pedidos.
- [ ] Componentes con shadcn/ui, accesibles y adaptados a móvil.

## Criterios de aceptación

- El flujo de compra completo funciona contra la API real.
- Las páginas del catálogo se renderizan en el servidor.
- Puntuación de accesibilidad de Lighthouse de 90 o más.
